Elffuss — how it fits together

one shared core · three products · nothing leaves the tab
the browser tab — everything below runs here no backend · no build · no install
the loop
agent.jsmodel → tool call → result → model. Six steps, one tool block.
context.jsWhat the agent still remembers when the history stops fitting. BM25 with endogenous IDF, line granularity, optional semantic fusion.
providers/litert (Gemma on WebGPU) · onnx (transformers.js) · api (opt-in, direct from the browser)
what it can do
skills.jsSKILL.md from any public repo, injected into the prompt. Self-editing: ask in chat and the skill rewrites itself.
tools/files, apps, vault, tasks, web, memory — each one behind an explicit permission.
rlm.jsRecursive LM: chunk → ask each part → merge → recurse. Plus the deliberating jury and the surgical patcher.
what it keeps
workspace.jsA folder on your disk: sessions, skills and apps as ordinary files. Inventory, wipe, downloadable copy.
vault + dbIndexedDB for state, AES-256-GCM for secrets. The vault is never exported in the clear.
mind.js · ceo.jsWhen you are idle it reviews your workspace and proposes improvements. It never edits on its own.
ClawThe chat is the interface. Apps don't exist: they are generated as HTML and rendered in the tab.claw.elffuss.utopiaia.com
CodeA VS Code-style IDE. Opens a real folder from your disk; the agent reads, searches and edits it.code.elffuss.utopiaia.com
TranslatorLive conversation translation, and skills that work while you talk — the surface is projected across origins.translator.elffuss.utopiaia.com
WebGPU · the model runs on your GPU File System Access · your folders, with permission Microphone · only while you talk IndexedDB + Cache · weights cached once
✕ No server of ours ever sees your prompts, your files or your audio — there is nothing to send them to. External model providers are opt-in, and their keys go straight from your browser to the provider.
